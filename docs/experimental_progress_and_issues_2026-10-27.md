# 阶段实验成果与问题总结

整理日期：2026-10-27（北京时间）。范围：MERIT / REZE 历史复现、跨数据集测试，以及最新 ReVALUE 记忆、比较和观察实验。本次整理不启动新实验。

**目前最明确的性能成果来自 REZE 候选复评。新增记忆与定向回看尚未形成稳定精度收益，当前主要瓶颈是观察事实的可靠性，以及模型对证据不足的处理。**

## 1. 已取得的性能成果

### 1.1 REZE 候选复评：全量验证取得提升

在 QVHighlights 全部 1,550 条 validation 查询上，使用官方 VeryGood 口径：

| 方法 | mAP | Hit@1 |
|---|---:|---:|
| REZE 原方法 B0 | 42.99 | 71.68 |
| B0＋候选独立复评 P_abs | 43.57 | 74.06 |
| B0＋双向成对比较 P_pair | **43.76** | **76.84** |

P_pair 相对 B0 提高 **0.771 pp mAP、5.161 pp Hit@1**。按源视频聚类的配对 bootstrap 95% 区间分别为 `[0.479, 1.064]` 和 `[3.488, 6.863]`；这是本次探索性配对统计，未做多重比较校正。P_pair 相对 P_abs 的 mAP 差异区间跨零，不能声称在该指标上已明确胜出。

两种复评固定 Top-5 候选，使用 B0 已见帧，仅置换候选原有分数；没有加入记忆、事件图或工具回看，也不能找回候选集合之外的高光。这是目前最有依据的局部改进成果。

来源：[REZE 全量结果](reze_fullval_results_2026-10-20.md)、[历史实验汇总](experimental_results_report_2026-10-22.md)。

### 1.2 历史复现提供了方法选择依据

MERIT 原任务适配完成 QVHighlights val1550，VeryGood mAP / Hit@1 为 **21.67 / 31.23**。后续固定 train100 的直接密集视觉评分 D0 为 **30.80 / 48.00**，高于同一开发集原 MERIT 的 **22.72 / 29.00**；追加 MERIT 检索选区复评 H1 为 **30.31 / 48.00**，没有进一步提升。

这些结果支持我们把后续主线转向更强的视觉评分与候选比较，但不同样本、模型、输入和预算的成绩必须分开解释。MERIT 属于任务迁移适配，不是复现原论文已有的 QVHighlights 分数。LongVT 与 VideoARM 的完整集或部分集结果保留在[此前复现实验总汇](reproduction_results_summary_2026-10-19.md)，不混入本轮 ReVALUE 对照。

## 2. ReVALUE 的实际进展与性能边界

目标是在 REZE 初始化之后，加入目的相关记忆、四态比较、定向补证和事件选择。五类价值保持为结果、信息、情感、动作、感官；相关辅助 cue 不替代该划分。

| 阶段 | 完成范围 | 当前结论 |
|---|---|---|
| R0 工程验证 | 固定 20 条及隔离修复 | 多帧输入、结构、引用、预算等运行条件已验证；不等于语义正确性通过 |
| R1 记忆对照 | 固定 20 条开发样本 | 决策记忆与直接比较逐查询指标一致，未证明稳定记忆收益 |
| R2 修复版 | 固定 100 条开发样本 | 100/100 完成、零技术回退、7 条实际配对观察；精度门槛未通过 |
| 来源、容量与观察诊断 | 672 次单帧观察、14 份记忆、37 次输出对照、60 次物体核查 | 部分工程缺陷已修复，观察内容仍未通过 |
| R3 / R4 | 尚未运行 | 完整真实闭环、独立确认和后续扩大验证仍缺结果 |

R2 在同一固定 100 条开发样本上的 VeryGood 指标如下，不能与 val1550 的均值直接比较：

| 条件 | mAP | Hit@1 | 端到端 token / B0 |
|---|---:|---:|---:|
| B0：原 REZE | 44.41 | 71.00 | 1.000 |
| E0：原 P_pair | **44.58** | **78.00** | 1.556 |
| C_direct4：四态直接比较 | 44.42 | 72.00 | 2.015 |
| E_memory：决策记忆，无新增观察 | 44.49 | 73.00 | 2.889 |
| E_uniform：记忆＋均匀观察 | 44.41 | 71.00 | 3.028 |
| E_targeted：记忆＋定向观察 | 44.41 | 71.00 | 3.029 |

两观察组全部 100 条预测向量均与 B0 相同。相对 E_memory，仅三条发生评分变化，三条 mAP 均下降。7 条触发样本的模型规划均为空，实际查证由控制器规则生成，不能据此宣称自主规划已经成功。

当前比较器仍会读取候选旧帧，初始化仍依赖 REZE 密集评分；这些结果不构成纯文本 memory-only 或节省密集初始化成本的证据。

来源：[R1 结果](revalue_r1_results_2026-10-25.md)、[R2 指标与阶段说明](revalue_current_experiment_plan_2026-10-26.md)、[总体执行方案 v3](revalue_execution_plan_v3_2026-10-23.md)。

## 3. 工程与机制层面的成果

### 3.1 来源绑定和运行可靠性

已修复事实与帧时间错配、片外证据误用于目标候选、空描述入库及部分结构化输出问题。离线完成 400 次排序重放，区分实现错误与按保守排序规则回到 B0 的正常行为。模型请求、原始响应、帧来源、预算及失败记录均保留。

最新 ReVALUE CPU 测试为 **150 项通过**。这验证了所覆盖的工程行为，不证明视觉理解正确，也不代表整个仓库所有测试均通过。

来源：[离线诊断](revalue_r2_offline_diagnosis_2026-10-26.md)、[来源绑定修复](revalue_frame_grounding_repair_results_2026-10-26.md)。

### 3.2 记忆容量改善已验证，评分收益尚未验证

对七条 query、两观察臂的 14 份记忆进行无损来源压缩，在完整图例、来源表与事实均计入 1,024 token 的条件下：

- 相同事实的总 token 从 **13,840 降至 10,339**，节省 **25.30%**。
- 14/14 视图无损还原，来源与候选引用约束保持。
- 同容量内补回 75 个完整旧条目，累计 **104 个旧事实 ID**；该数值跨视图累计，并非独立去重事实数。

目前只证明了容量和引用约束可以保持，尚未验证比较器能否同等理解压缩表示，或是否提高 HD 指标。来源压缩 A/B/C 比较尚未启动。

### 3.3 输出完整性改善，但事实错误仍在

37 次固定图像对照仅移除描述字段的字符上限，改善了句子完整性；原输出 token 上限保持不变。手机、狗、人物关系等视觉误判仍存在，说明修复截断不能替代内容核查。

来源：[记忆压缩与输出探针结果](revalue_memory_compaction_results_2026-10-26.md)。

## 4. 最新物体核查揭示的问题

固定 15 张图、30 个物体存在性问题，每题运行 direct 与 evidence_first 两种提示，共 **60/60 次完成**。

| 读数 | direct | evidence_first |
|---|---:|---:|
| 与推理前助手参考标签一致 | 24/30 | 24/30 |
| 明确正例保留 | 14/14 | 14/14 |
| 明确反例正确否定 | 10/10 | 10/10 |
| 六个模糊例选择无法判断 | **0/6** | **0/6** |

手机断言得到纠正，但模型仍肯定水花中的“狗”和裁切登机设施中的“廊桥”；其余四个模糊对象被判为不存在。两臂 30/30 个状态完全相同，证据优先提示多用约 **20.70% token**，没有改善状态判断。部分解释还补出了没有清晰依据的“湿毛”等细节。

CPU 检查确认 `cannot_determine` 在实际 tokenizer 和本轮语法约束中可生成；最大输出 59 token，未触及 160 token 上限。因此本次失败不能归为该选项被屏蔽或输出截断。更值得检验的是：输入能否支持辨认，以及模型能否把“看不清”与“不存在”区分开。

这批是刻意选择的开发案例，参考标签来自助手，尚无独立人工验证；24/30 不能解释为数据集总体准确率。内容关未通过，结果未写入正式活动记忆，未产生新 HD 指标。

来源：[物体核查完整报告](revalue_object_presence_results_2026-10-27.md)、[冻结协议](revalue_object_presence_protocol_2026-10-26.md)。

## 6. 当前关键问题与尚不能下的结论

1. **事实可靠性。** 来源正确只能证明看了哪一帧，不能证明描述与画面一致；错误观察可能进入记忆并影响后续比较。
2. **不确定性处理。** 模糊、遮挡和画外对象容易被猜成存在或不存在；更长提示目前没有解决这一问题。
3. **候选区分度。** 四态比较大量为相当或未决，观察后未形成有效胜负关系。需区分真实相似、证据不足和比较过于保守，不能强迫选赢家。
4. **记忆信息保留。** 新来源信息可能挤掉旧区分证据；压缩解决了容量的一部分，语义可用性和评分收益仍待验证。
5. **自主闭环缺口。** 自动发现证据缺口、有效规划、连续补证、事件发现、边界修订和最终集合选择，尚无完整真实模型闭环结果。
6. **成本与收益不匹配。** R2 定向观察端到端 token 约为 B0 的 3.03 倍，未取得指标提升；初始化和固定 Top-5 也限制了成本降低与候选外召回。
7. **验证范围有限。** ReVALUE 使用反复查看的开发样本，语义诊断缺少独立人工复核，不能据小样本结论宣称稳定泛化。

现有证据支持“当前实现尚未获得记忆/定向观察收益”，不支持直接断言记忆无用、长视频必然更有效，或模型规模是唯一原因。

## 7. 下一步推进顺序

**优先验证增加针对性的视觉信息，暂不继续仅加长同类提示。** 固定现有 30 题及参考标签，比较“全图＋全图重复对照”与“全图＋原始分辨率局部裁剪”。两臂采用同一核查提示和同样展示帧数，仅改变第二路画面；ROI 在新结果产生前固定，成本据实记录。

保留清晰正反例与模糊例，检查新增细节能否补证、是否损伤已有正确判断，以及无法补证时是否合理保持 unknown。原始画面本身模糊或遮挡时，裁剪可能无效，不能把低分辨率图放大当成新增信息。

之后分别验证可辨识性与入库规则、短时连续输入对动作证据的作用。观察器通过固定 28 窗口及全部拟入库事实审查后，再回到统一事实集上的来源表示/容量 A/B/C 比较，随后按原门槛复核 100 条并开展独立确认。完整 R3 功能验收另立协议，不能用它绕过精度失败直接扩大性能实验。

上述为后续方向，本次未启动新 GPU 任务。原精度门槛、已完成预测、失败记录与历史计划均保留。
