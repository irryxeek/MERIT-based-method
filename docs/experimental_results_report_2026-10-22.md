整理日期：**2026-10-22（北京时间）**。覆盖本项目已归档的 MERIT、LongVT、VideoARM、CLIP、VTG-GPT、REZE 实验，以及 REZE 在 QFVS、MR.HiSum、TVSum 上的迁移测试。

本报告根据已完成的指标 JSON、运行记录和离线诊断整理。QVHighlights 的 REZE 全量结果与三个已完成迁移实验的最终指标已直接核对；较早实验沿用归档报告及其证据入口。本次只整理文档，未新增模型推理或改变原预测。所有指标以 **%** 表示，差值以**百分点（pp）**表示；不同数据集的指标不能直接比较大小。

## 1. 主要结论

1. **QVHighlights 当前最好结果是 REZE B0＋P_pair：VeryGood mAP 43.76、Hit@1 76.84。** 相对 B0 提高 0.77 / 5.16 pp，配对区间均高于零。收益更明显地体现在首个高光选择，mAP 点估计增幅仍未达到原定 1 pp 目标。
2. **MERIT 的复杂记忆与回看尚未建立稳定的精度收益。** train100 上直接密集视觉评分 D0 优于原 MERIT；加入局部复评未进一步改善。固定 train20 中，证据图、细粒度记忆和 cue 评分均未超过 D0。R1 改善了纯记忆读取，但不能据此认为已等效替代直接视觉评分。
3. **TVSum 迁移有正收益。** UMT 固定 val10 的 Top-5 mAP 为 61.32；全 50 条补充结果为 54.89，分别超过同口径随机期望 18.77 / 13.57 pp。
4. **MR.HiSum 的高光排序和摘要质量出现分化。** 可用测试集 1,888 条的 mAP50 / mAP15 为 57.00 / 23.90，略优于随机；摘要 F1 为 38.27，低于常数评分经相同摘要生成器得到的 56.61。
5. **QFVS 仍处于问题定位阶段。** 四查询 Oracle 语义 F1 为 38.63，低于同预算均匀选片 50.15；SVHighlights 尚无有效 REZE 指标，TVHighlights 尚无本地可用视频及标注。

## 2. 方法与评价范围

### 2.1 方法定义

| 方法 | 本地实际执行内容 |
|---|---|
| MERIT 原适配 / M0 | 每 10 秒生成描述及 event/object/summary 三键；检索与时序邻域提供证据，输出完整 2 秒高光分数。 |
| LongVT Global / Tool | 冻结 LongVT-RFT；Global 观察 64 帧，Tool 允许额外局部裁剪；compact 与 v2b 使用不同输出协议。 |
| VideoARM M1 | 先对 2 秒片段代表帧密集评分，再执行控制器、Scene/Clip 工具及记忆循环。 |
| D0 / H1 | D0 每 2 秒取一张代表帧，分批直接评分；H1 在其后用 MERIT 检索选区并复评，未向局部评分器加入记忆文本或新帧。 |
| CLIP / VTG-GPT | 前者使用 2 秒中点图像与 query 相似度；后者复用作者中间 caption 和 query 改写文本进行评分。 |
| REZE B0 | 3 秒窗口、2 FPS、完整窗口 6 帧，以 Yes/No 概率评分，经含共享边界的逐秒曲线映射到数据集评价网格。 |
| P_abs / P_pair | 固定 B0 前五候选及已观察帧，分别做绝对复评、双向相对比较，只重排原前五格的分数。 |

MERIT、VideoARM 当前适配及 REZE 使用 `Qwen3-VL-8B-Instruct`，revision 为 `0c351dd01ed87e9c1b53cbc748cba10e6187ff3b`；LongVT 使用其发布的 RFT 权重。表列实验没有进行针对这些数据集的权重训练。不同方法的骨干、输入、服务与预算未全部统一，跨方法分差不能单独归因于某一模块。

### 2.2 评价口径

| 数据集 | 本报告范围 | 主要指标与读出 |
|---|---|---|
| QVHighlights | 完整 val：1,550 查询、1,519 视频片段、474 源视频；另有训练开发子集 | 官方 2 秒网格 HD mAP、Hit@1，主报 VeryGood；VideoARM 另有 MR 指标。 |

### 3.2 REZE 改进及配对分析

每个 query 固定五个候选，每候选最多四帧，全部来自 B0 已看过的采样位置。10 个无序候选对各用两个输入顺序，P_abs、P_pair 每种方法各增加 20 次调用。P_pair 在正向概率 ≥0.6、反向 ≤0.4 时采纳比较优势；最终只置换前五格原分数，其他位置不变。

按 474 个源视频聚类、10,000 次配对 bootstrap、seed=42，得到以下探索性 95% 区间，未做多重比较校正：

| 比较 | VeryGood mAP Δ [95% CI] | Hit@1 Δ [95% CI] |
|---|---:|---:|
| P_abs − B0 | +0.582 [0.289, 0.879] | +2.387 [0.581, 4.177] |
| P_pair − B0 | +0.771 [0.479, 1.064] | +5.161 [3.488, 6.863] |
| P_pair − P_abs | +0.189 [−0.059, 0.442] | +2.774 [1.307, 4.285] |

P_pair 对 B0 的收益有本次配对统计支持；相对 P_abs，其 mAP 优势仍不确定。只重排五个候选无法找回候选之外的高光，三组仍各有 146 条最高分并列。本轮没有接入 memory、event graph、回源查证或训练。

此前独立 train explore100 的 B0 / P_abs / P_pair 为 **44.41 / 44.71 / 44.58 mAP**、**71 / 76 / 78 Hit@1**，均未通过原 +1 pp mAP 门槛。全量验证是后来授权的扩大检验，不追溯改写该停止决定。

### 5.1 TVSum：50 条全部完成

完成时间：**2026-10-22 01:23:35 CST**。50 条视频共约 3.50 小时，正式评分 4,213 个窗口，得到 6,266 个 2 秒片段分数。统一 query 为 `Highlight of this video.`，不输入标题、类别或标签。

|---|---:|---:|---:|---:|

| all50，补充结果 | **54.89** | 46.56 | 41.32 | +13.57 [9.69, 17.38] |

UMT 协议对每位标注者按严格大于其中位数二值化，在预测 top-5 内计算作者梯形 AP，分母为该前缀中的正例数。它不是常规完整排序 AP，也不是 TVSum 原始摘要 F1。本轮不计算 TVSum 摘要 F1。

all50 包含 UMT 的 40 条训练划分视频，本次未用于训练或提示调参；该分数不能混作固定 val10 成绩。其余 40 条平均为 53.29，因此 61.32 与 54.89 的差异来自统计范围。全 50 条中 39 条高于随机期望、36 条高于常数。

全部正式请求都有 Yes/No 双侧概率，无整视频常数预测。第二分片首次 smoke 遇到 vLLM 多模态错误，按原配置重试后完成，未跳过视频。来源：[执行与评估报告](reze_tvsum_execution_2026-10-22.md)。

| MR.HiSum pilot100 | 6,959 | 6,968 | 6,129,511 | 单卡 worker 26.04 分钟。 |
| MR.HiSum full1888 | 128,309 | 128,327 | 111,886,086 | 双卡墙钟 3.91 小时；累计 worker 7.64 小时。 |
| QFVS pilot4 | 20,356 | 20,368 | 11,602,604 | 单卡 worker 35.05 分钟。 |

P_pair 含 B0 的冷启动输入＋输出 token 总量约 **70.11M，是 B0 的 1.553 倍**；本次复评实际复用了 B0 缓存。两组共享批次，不能把账本均分时间当成每种方法的独立延迟。TVSum 两分片并非完全同步启动，11.81 分钟包含分片间等待和重试。

CLIP 单卡 16.79 分钟；VTG-GPT 96.95 秒仅覆盖读取已有文本与评分，不含 caption/query 生成。硬件、并发、缓存和计算边界不同，上述时间不构成统一端到端效率排名。

### 6.2 MERIT 历史主实验与开发开销

原 MERIT 主实验累计 VLM 57,408 次实际尝试、约 113.80M 输入＋输出 tokens；串行主运行记录为 22.61 小时。VideoARM 部分 HD 四路并发至暂停为 2.75 小时，完成范围不同，不能直接换算算法加速比。

| 开发运行 | 逻辑请求 / 实际尝试 | 新增工作进程墙钟 |
|---|---:|---:|
| train100：M0/D0/H1 共享流程 | 4,204 / 4,215 | 81.42 分钟 |
| train20：证据 pilot v4 | 342 / 377 | 15.43 分钟 |
| C10/F2 修复前 / 修复后 | 98 / 111；112 / 116 | 12.49 / 7.43 分钟 |
| A/B/C 输入消融 | 42 / 42 | 1.87 分钟 |
| 全片建库＋R0/cue 评分 | 340 / 356 | 35.87 分钟 |
| R1 复用记忆后文字评分 | 20 / 20 | 3.00 分钟 |

这些时间不含模型启动，复用缓存的行不含历史建库或 D0 成本；R1 的 3 分钟不能作为完整方案耗时。此前失败版本成本及同样本时间比较保留在[历史总汇第 7–8 节](reproduction_results_summary_2026-10-19.md)，不能从研究总投入中删除。

## 7. 结果差异及适配判断

### 7.1 查询相关性、内在高光价值和摘要覆盖是不同目标

QVHighlights 的具体事件 query 与 REZE 短窗核验较一致。TVSum、MR.HiSum 当前使用抽象的 `Highlight of this video.`，系统提示仍要求严格动作核验；模型没有显式获得全片主题或跨事件比较基准。QFVS 又要求查询概念相关性与摘要代表性，而非只挑最高分局部片段。

这支持优先检验任务目标适配，但不能在未消融前断言提示是唯一原因。当前没有音频/ASR 模态对照，也不能把遗漏语音直接确定为主要瓶颈。

### 7.2 MR.HiSum：排序有效不保证背包摘要有效

对全部 1,888 条的已有 CPU 诊断如下，均为逐视频统计后取平均：

| 统计量 | REZE | 常数评分 | 参考摘要 |
|---|---:|---:|---:|
| 摘要占视频时长 | 14.729% | 14.738% | 14.788% |
| 选中镜头数 | 11.40 | 15.16 | 12.91 |
| 入选镜头平均时长 | 2.86 秒 | 2.06 秒 | 2.45 秒 |

摘要预算几乎相同，质量差异并非简单来自选得太少。作者背包以镜头均分为价值、时长为成本，常数评分具有多选短镜头的结构性倾向，并不是随机摘要。REZE 分数的平均变异系数为 1.27，真值为 0.75；概率较尖锐与覆盖变化可能有关，具体因果仍需固定评分或固定选择器的对照。

用真值分数通过同一冻结摘要生成器，F1 为 **99.72**，零补齐后 1,679/1,888 条完全重建参考掩码。这是**使用标签的流程检查，不是模型成绩**，说明当前低 F1 不能主要归咎于既有尾部边界处理。

### 7.3 QFVS：概念歧义与集合选择均需检查

P02 的 73 个入选片段在官方概念标签中均未命中 Building 或 Boat；已抽查的高分画面为玩具组装。动作核验提示可能把 Building 理解为“搭建”，但尚无提示消融证明因果。

P01/P03 的概念命中提高，F1 仍低于均匀选片。P03 的 43 个片段集中为 17 个连续区间，最长连续 50 秒；当前 top 2% 没有集合级覆盖或去重。时间集中是观察结果，语义冗余及其影响还需独立验证。

TVSum、MR.HiSum、QFVS 的 No 输出比例分别约 93.19%、91.30%、99.54%，但正式窗口均取得双侧概率。高 No 比例不是推理失败率，修复应以排序和任务指标衡量。

### 7.4 已有适配与下一步建议

| 数据集 | 已完成的适配 | 优先验证的增量 |
|---|---|---|
| QVHighlights | 2 秒评分接口、官方 HD 评估、固定候选复评与比较 | 先检查前五覆盖及并列瓶颈，再决定是否增加新证据。 |
| TVSum | 通用 query、2 秒标签、UMT 评价及固定划分 | 先单独改为片段重要性核验；再独立检验标题/主题或 P_pair。 |
| MR.HiSum | 通用 query、1 秒到 5 秒 HD 映射、KTS＋15% 摘要 | 优先在训练/验证小样本检验重播价值评分；摘要校准另设对照。 |
| QFVS | 双概念 OR、5 秒评分、2% 预算、语义 F1 | 分开验证名词概念核验与固定评分下的去重/覆盖。 |
| SVHighlights | 数据与评分接口已接入，运行尚未完成 | 修复启动链路并取得有效基线后，再判断运动事件适配。 |

建议顺序为 **TVSum 最小提示对照 → 固定候选比较 → MR.HiSum 小规模 HD 适配**；QFVS 先修正必要接口，暂不扩展全量。保持原 B0、相同输入预算和评价器，将新增条件单独命名，避免同时改变记忆、提示、候选和帧密度。本报告不启动这些新实验。

## 8. 结论边界与证据入口

当前 QV validation、MR.HiSum 可用 test、TVSum val10 均已查看，train20 又经过多轮开发，不能声称它们是后续方法完全未见的最终检验集。置信区间不覆盖模型预训练、提示选择、缺失视频和重复开发等系统偏差。工程成功、合法结构化输出及标签诊断分数也不能替代方法有效性证据。
