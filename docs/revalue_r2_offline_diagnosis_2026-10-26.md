# ReVALUE R2 离线诊断：回看为什么没有转化为排序收益

日期：2026-10-26。按[现阶段实验方案](revalue_current_experiment_plan_2026-10-26.md)步骤一执行，使用已完成 R2 v3 的不可变产物。离线诊断没有调用模型；新的观察对照按[独立协议](revalue_r2_observation_probe_protocol_2026-10-26.md)另行计费。

## 1. 已完成的检查与结论

核验全部 100 条记录的完成收据，逐条件重放 **400 次排序与完整评分导出**，全部与保存结果一致。结合源码可确认：两观察组回到 B0，是双向比较没有形成胜负边后的既定行为，未发现导出错误。

保存原 R1 固定 20 条与全部 7 条实际回看案例，交集 4 条，合计 **23 条诊断记录**。其中 7 条均制作源帧核对图，共核验 **141 个被引用帧检查项**的原始 RGB 哈希和 PTS；检查项可能跨动作重复，不等于新增唯一帧数。助手查看了七份图，独立人工审阅仍未进行。

当前证据支持三个具体问题：**观察中存在不被引用画面支持的查询内容；活动记忆缺少新增事实的明确时间位置；比较存在事实、理由和结论不一致。** 记忆淘汰同时发生，但不能单独解释全部退化。

## 2. 不是评分导出丢失了已判定的赢家

100 条每条件包含 1,000 个无向候选对；全部有向比较均保留。

| 条件 | 双向确定胜负 | 双向支持并列 | 未决 |
|---|---:|---:|---:|
| C_direct4 | 4 | 946 | 50 |
| E_memory | 6 | 962 | 32 |
| E_uniform | 0 | 971 | 29 |
| E_targeted | 0 | 968 | 32 |

E_memory 的六个确定胜负对全部位于 881、7971、1129。均匀回看后，3 对变成并列、3 对变成未决；定向回看后，6 对全部变成未决。这不是说每个单向判断都消失：均匀组仍有 9 个单向 `a_better`，定向组有 9 个 `a_better` 和 2 个 `b_better`，但反向结论不足以建立一致胜负边。

两观察组 100 条完整评分向量与 B0 逐元素一致；相对 E_memory，只有上述三条改变。原 E0/P_pair 是 Yes/No 概率比较与其排序协议，没有相同的自然语言理由；不能将其概率和新四态结论当成只差记忆的同一比较器。

**已复现：**现有保守导出会把无胜负边的候选按 B0 排回。是否应改变排序规则属于新的方法对照，本轮不通过强制赢家或直接沿用旧优胜分数修饰结果。

## 3. 新观察的时间位置与活动记忆

两组共 28 个观察响应、79 条事实。按事实引用的源帧 PTS 与目标 2 秒格比较，允许一个源帧时长的边界容差：

| 引用位置 | 事实数 |
|---|---:|
| 全部位于目标内 | 57 |
| 同时包含目标内外 | 6 |
| 全部位于目标外 | 16 |

16 条片外事实**不等于 16 条错误事实**：上下文本来就可用于理解事件。问题在于，`update_memory()` 将事实记为某候选附近的上下文，保留 `candidate / frames / kind`，却没有将引用帧 PTS、目标区间内外关系放入活动记忆。比较器可见原候选旧帧的时间映射，但看不到这些新增事实的完整时间映射。

例如 1129 的目标候选 24 为 48–50 秒，均匀观察的“淋浴小腿”引用在 45.75、46.18、46.61、47.05 秒；其中后两帧已切到室内讲话。实际 48–50 秒又从室内讲话切到机场飞机。把候选附近确实出现过的淋浴画面用于说明目标片段同样符合 query，会混淆片外证据与片内内容。

**已复现：**来源时间信息在活动记忆接口中缺失。**尚待对照：**明确保留时间归属后能否减少误判，不能据字段缺失直接量化其全部精度影响。

## 5. 记忆淘汰存在，但不是单一根因

| qid | 旧活动记忆 token | 均匀更新后 token / 淘汰旧事实数 | 定向更新后 token / 淘汰旧事实数 |
|---|---:|---:|---:|
| 5172 | 995 | 1014 / 8 | 967 / 6 |
| 881 | 853 | 969 / 3 | 1024 / 5 |
| 9841 | 857 | 978 / 6 | 1017 / 0 |
| 7971 | 1013 | 1019 / 11 | 1014 / 14 |
| 2973 | 855 | 988 / 8 | 1006 / 9 |
| 3478 | 980 | 977 / 3 | 990 / 3 |
| 1129 | 829 | 981 / 0 | 1016 / 5 |

均匀/定向组分别淘汰 39/42 个原活动事实 ID，容量均未超过 1,024 token。旧事实、被淘汰事实和当前可用事实没有混为同一输入。

反例：1129 的均匀组旧事实全部保留，仍失去两个确定胜负对；881 原胜负对 39/42 的关键旧事实在两观察组都保留，仍失去双向一致性。因此“淘汰导致所有退化”不成立。7971 的淘汰较多，仍值得单独验证保留策略，不能从当前混合变化推断因果。

## 6. 比较器还存在语义不一致

881 均匀比较 39→42 的输出将双方资格都标为 satisfied、结论为 tie，但理由同时写明 B 是飞机画面且没有动作匹配。反方向又引用飞机观察事实，称双方均为泳池活动。

1129 定向比较 24→18 的理由同时写“双方都是淋浴小腿”与“A 是飞机、B 是淋浴”，结论仍为 tie。其反方向能给出正确区分。合法双侧引用只保证 ID 存在及来源归属符合接口，不能保证引用支持结论。

在全量字段中，没有发现 `tie` 同时带 `satisfied` 与 `violated` 的直接枚举冲突；问题发生在画面、自然语言理由与这些字段之间。仅加一个枚举一致性校验不会解决所见案例。

**有案例支持：**比较器会把相关内容扩散到另一候选，并存在方向不一致。是否由提示、证据组织或模型能力主导，尚未隔离；不在本轮同时调整比较提示。

## 7. 已选择的最小对照与后续顺序

先运行 **28 次相同源帧的观察问题消融**：原问题直接复述 query，对照改为固定中性画面描述。只改观察问题，保留像素、时间、schema、系统提示和输出预算。这样先判断错误事实是否受查询诱导，避免一开始同时改记忆、比较和排序。

该对照不生成新的高光指标。下一阶段根据事实质量决定是否接回未改动的记忆/比较器；时间归属与比较语义另作独立实验，不默认查询盲观察会解决所有问题。原 +1 pp 精度门槛不变。
