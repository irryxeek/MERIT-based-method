# CLIP 与 VTG-GPT 零样本高光检测复现实验

> 发布说明（2026-10-22）：保留原报告的日期、指标和结论；调整引用链接与机器路径。历史命令和本地资料不表示本仓库附带完整运行环境，详见[报告发布约定](../report_publication_workflow.md)。

日期：2026-10-19。状态：**两组全量推理、官方评估和结果归档均已完成**，两组均为 1,550/1,550 成功。
范围：QVHighlights validation，1,550 查询、1,519 视频片段、474 源视频。

## 实际执行的方法

- **CLIP ViT-B/32**：从原视频按每 2s 一个中心帧提取特征，与原始 query 计算余弦相似度。
  使用 OpenAI 官方权重和预处理；没有训练、提示改写、LLM 打分或平滑。
- **VTG-GPT**：使用作者发布的 caption 和五个 query 改写，通过冻结 Sentence-BERT
  和原始公开评分代码输出完整分数。没有重新执行 MiniGPT-v2 描述生成和 Baichuan2 改写。
- **MERIT 历史参照**：复用已有完整 val 输出，不是本轮新跑；其中九条历史失败的原输出仍在分母内。

详细设置、版本、数据哈希及尾部处理见 [实验协议](PROTOCOL.md)。本轮主实验只评 HD，
不将 MR 候选指标混入高光检测分数，也没有运行 REZE。

## 完整验证集指标

两组均使用同一官方评估器、同一完整 qid 集合。表中均为百分数，主指标为 VeryGood。

| 方法 | Fair mAP / Hit@1 | Good mAP / Hit@1 | VeryGood mAP / Hit@1 | 完成 / 失败 |
| --- | --- | --- | --- | --- |
| CLIP ViT-B/32，中点帧余弦相似度 | 69.81 / 77.29 | 59.57 / 74.65 | **36.50 / 61.68** | 1550 / 0 |
| VTG-GPT，作者中间数据评分 | 67.02 / 77.03 | 57.54 / 74.19 | **35.10 / 61.23** | 1550 / 0 |
| MERIT 原适配，历史完整 val | 46.69 / 41.68 | 37.85 / 39.42 | 21.67 / 31.23 | 1541 / 9，失败输出保留 |

**本轮简单 CLIP 基线的 mAP 高于 VTG-GPT，两者均超过此前 MERIT 适配。**
这说明后续方案需要先超过较强的连续相似度基线；尚不能据此单独归因于记忆粒度、
caption 模型或 LLM 评分，因为方法的模型、输入和计算流程同时不同。

## 同样本配对比较

差值使用未舍入逐查询指标，单位为百分点。95% 区间按 474 个源视频聚类，
seed=42，10,000 次配对 bootstrap；属于探索性区间，未做多重比较校正。

| 差值 | VeryGood mAP Δ [95% CI] | Hit@1 Δ [95% CI] |
| --- | --- | --- |
| CLIP − VTG-GPT | **+1.40 [0.72, 2.07]** | +0.45 [−2.36, 3.27] |
| CLIP − MERIT | +14.83 [14.03, 15.64] | +30.45 [27.38, 33.38] |
| VTG-GPT − MERIT | +13.43 [12.67, 14.18] | +30.00 [26.99, 32.92] |

CLIP 相对 VTG-GPT 的 mAP 区间不跨零，Hit@1 区间跨零；不能把两个指标都表述为显著提升。
CLIP 与 VTG-GPT 的逐查询 mAP 胜/平/负为 826/49/675。
两组整段常数预测均为 0；最高分并列分别为 2 和 120 条。历史 MERIT 有 35 条整段常数、
1,444 条最高分并列。连续分数的区分性值得作为后续诊断方向，但这些计数不证明因果。

历史 MERIT 的预测没有 `query` 字段，已通过 qid、vid 及历史标签 SHA256 进行身份核验，
重新调用同一官方评估器得到完全相同的旧指标。没有重写历史预测或替换其失败输出。

## 与论文数值的关系

[VTG-GPT 论文表 4](https://arxiv.org/html/2403.02076v1#S4.T4) 报告 val 的 36.08 / 62.29；
本轮为 35.10 / 61.23，分别低 0.98 / 1.06 个百分点。
这是作者已发布中间数据上的公开代码评分复现，没有达到论文表中数值，也不等于端到端重建。
论文描述平均五个改写；当前仓库代码对原 query 加五个改写逐曲线归一化后平均。
代码、中间数据和环境的历史差异尚未逐项消融，不能将差距确定归因于其中某一项。

[QVHighlights 原论文表 3](https://arxiv.org/html/2107.09609) 中 CLIP 为 test 的 31.30 / 61.04。
本次使用 val，不把两个 split 的数值差异解释为复现偏差或算法提升。

## 质量核验与成本边界

两组均先通过五条 smoke。VTG-GPT 缓存与原始未缓存实现的分数、候选逐值一致；
CLIP 批量与单图编码通过 FP16 容差检查。10 项 pytest 和 Ruff 检查通过，两个官方仓库保持无修改。
首次 VTG-GPT smoke 的 NumPy 序列化错误及源码已保留；修复不涉及评分公式。

VTG-GPT 已发布 caption 的 13 条末尾缺格显式补零，并验证与原始短向量的官方 HD 结果完全一致。
CLIP 对 1,519 个视频共编码 **113,633 张代表帧**，共享视频在多 query 间复用特征；
全部查询共输出 115,953 个 clip 分数。15 个视频的末尾不完整 clip 使用同一 clip 内最后有效帧，
逐视频记录实际时间戳、源视频和特征哈希。
其余错误停止报错，不以成功子集或静默丢弃替代全量结果。

| 方法 | 全量进程墙钟 | 计时范围 |
| --- | --- | --- |
| CLIP | **1007.23 秒，16.79 分钟** | 模型加载、视频读取、预处理、文本/图像编码、保存；复用 smoke 的 5 个视频特征 |
| VTG-GPT | **96.95 秒，1.62 分钟** | 模型加载、已有文本读取、评分/候选计算和保存 |

两组各使用一张 RTX 4090，CLIP 为 GPU 7，VTG-GPT 为 GPU 6。CLIP smoke 另外用时 10.33 秒，
VTG-GPT 成功 smoke 另外用时 9.36 秒；下载、环境准备、失败工程 smoke 和官方评估不在主表墙钟内。
CLIP 全部视频的视觉编码累计约 44.76 秒，解码/预处理工作线程累计约 4001.08 秒；
后者包含四线程并发，不能与墙钟直接相加。全量运行没有自动重启或查询重试。

VTG-GPT 的 caption/query 生成成本未测，因此不能将其评分耗时与 CLIP 原视频推理耗时
的比值当作端到端速度优势。后台任务均已正常退出、释放 GPU。
