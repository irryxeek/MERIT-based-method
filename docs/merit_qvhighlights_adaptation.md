## 任务定位

目前实现的是一套**基于 MERIT 的免训练、查询相关高光检测方案**：保留“多键记忆检索＋时序邻域扩展＋多轮检索”，新增适配 QVHighlights 的全时间轴评分模块。

原论文主要评估视频问答，因此当前工作属于任务迁移适配，并非复现论文已有的 QVHighlights 分数。现阶段只进行一套冻结模型的主实验。

## 整体流程

**视频 → 分段描述与三键记忆 → 查询驱动检索 → 邻域证据提取 → 多轮补充检索 → 每 2 秒高光评分 → 官方评估**

| 模块 | 当前实现及适配内容 |
| --- | --- |
| 模型配置 | **Qwen3-VL-8B-Instruct** 负责描述、键提取、证据过滤、检索决策和评分；**Qwen3-Embedding-4B** 负责文本检索。模型均冻结。 |
| 记忆构建 | 视频按 **10 秒**切分，每秒采样一帧，图像最长边 448 像素。先生成英文描述，再从描述中提取检索键。记忆构建不使用查询，可以复用。 |
| 多键表示 | 沿用 MERIT 的无字幕三键方案：**event** 表示动作与交互，**object** 表示对象及状态变化，**summary** 表示片段整体语义。不引入音频或对话键。 |
| 多键检索 | 分别计算查询与三个键的余弦相似度，取最大值作为片段检索分数。每轮选择 **3 个尚未检索的片段**，保留不同时间位置的独立身份。 |
| 时序邻域扩展 | 对检索片段向前、向后各扩展 **1 个记忆片段**，从邻域描述中提取与查询相关的证据，并保留时间 ID。邻域主要补充文本上下文，视觉输入来自检索锚点。 |
| 多轮决策 | 将原始查询、已检索描述、图像和邻域证据交给模型，判断是否足够识别高光；不足时改写检索查询。最多 **3 轮、9 个锚点、约 90 帧**。 |
| 高光评分 | 新增密集评分模块：结合**全视频描述＋检索图像＋邻域证据**，为每个 **2 秒区间**预测 0–100 分，每批处理 15 个区间。 |
| 评估对接 | 输出 QVHighlights 所需的完整分数序列，使用官方评估器，主要报告 **VeryGood mAP、Hit@1**，同时记录 Fair/Good 指标及失败情况。 |

## 主要任务适配

最主要的任务适配，是把 MERIT 的“证据是否足够回答问题”，改为“证据是否足够识别查询相关高光”，并把最终答案生成改成**覆盖整个视频的时间区间评分**。

检索相似度负责选择证据，最终高光分数由视觉模型另行预测。评分通过固定提示词完成，没有训练额外的高光检测预测头。

例如，一个 **150 秒视频**会形成约 **15 条记忆**，最终针对每条查询输出 **75 个高光分数**。未被检索到的区间仍依据其描述评分，不会直接置零；各评分批次使用相同的固定评分标准：

- 0：与查询无关。
- 25：弱相关或背景相关。
- 50：部分或中等相关。
- 75：明确相关。
- 100：非常清晰、突出的查询相关内容。

允许中间分值，不要求每个批次都出现最高分或最低分。

## 实验约束与可复现性

- 训练集固定 **5 个不同视频**仅做工程检查；主实验使用验证集 **1,550 条查询、1,519 个视频**。
- 推理输入与高光标签隔离，没有训练、消融或依据验证集指标调参。
- 模型生成温度固定为 0；固定模型版本、提示词、数据清单及实验配置。
- 请求失败后保留失败记录，整条查询零分回退，并保留在评估分母中。零分回退不表示该查询的评估指标必然为零。
- 保存原始模型响应、检索轨迹、逐查询结果及缓存来源，支持自动监控和断点恢复。
- 对实际视频尾段短于标注、但缺失不足完整 2 秒的情况，记忆区间截到实际可见时长，评分仍保留官方 2 秒网格。

## 当前局限与研究切入点

当前需要关注两个方法层面的局限：

1. **10 秒记忆到 2 秒评分的细粒度定位能力。** 单条描述覆盖较长时间，尤其在未检索到直接视觉证据的区间内，模型需要依据较粗的描述推断更细的时间位置。
2. **全视频描述与检索证据各自的贡献。** 当前评分器额外读取全视频描述，尚未通过消融证明三键检索和邻域扩展的独立增益。

此外，分批评分之间的一致性、描述生成超长导致的失败，以及模型输出的并列分数，也需要结合最终结果分析。当前实现可作为后续高光检测方法改进的起点，尚不能据此声称已验证方法优势。
